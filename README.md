# Linear Regression Projects

A collection of beginner-friendly machine learning projects demonstrating **Simple and Multiple Linear Regression** using Python and scikit-learn. Each project follows the same end-to-end workflow: load data → split into train/test sets → train a model → predict → evaluate → visualize.

## Projects

### 1. Salary Prediction (`salary_project.py`)
Predicts salary based on years of experience.

- **Dataset:** `Salary_dataset.csv`
- **Feature (X):** Years of experience
- **Target (y):** Salary
- **Output:** Scatter plot of actual vs. predicted salaries, plus evaluation metrics printed to the console.

### 2. Trip Duration vs. Distance Traveled (`Train_Project.py`)
Predicts distance traveled based on trip duration.

- **Dataset:** `train.csv`
- **Feature (X):** Trip duration
- **Target (y):** Distance traveled
- **Output:** Scatter plot of actual vs. predicted distance, plus evaluation metrics printed to the console.

### 3. Car Selling Price Prediction (`car_selling_price.py`)
Predicts a used car's selling price using **Multiple Linear Regression**.

- **Dataset:** `cars24-car-price-clean2.csv`
- **Features (X):** Year, kilometers driven, mileage
- **Target (y):** Selling price
- **Output:** Scatter plot of actual vs. predicted selling price (with an ideal-fit reference line), plus evaluation metrics printed to the console.

## How It Works

All three scripts follow the same structure (`car_selling_price.py` uses multiple features as input and plots actual vs. predicted values against each other, rather than against a single feature):

1. **`load_data()`** — Reads the CSV file and separates it into features (`X`) and target (`y`).
2. **`split_data()`** — Splits the data into training and test sets (80/20 split) using `train_test_split`.
3. **`train_model()`** — Fits a `LinearRegression` model on the training data.
4. **`predict()`** — Generates predictions on the test set and prints a comparison of actual vs. predicted values.
5. **`evaluation()`** — Prints model performance metrics:
   - Mean Squared Error (MSE)
   - Root Mean Squared Error (RMSE)
   - R² Score
6. **`plot()`** — Visualizes actual vs. predicted values using `matplotlib`.

## Requirements

- Python 3.x
- pandas
- numpy
- scikit-learn
- matplotlib

Install dependencies with:

```bash
pip install pandas numpy scikit-learn matplotlib
```

## Usage

Clone the repository and run either script directly:

```bash
git clone https://github.com/Aman-tech730/Linear-Regression-projects-.git
cd Linear-Regression-projects-

# Run the salary prediction project
python salary_project.py

# Run the trip duration vs. distance project
python Train_Project.py

# Run the car selling price prediction project
python car_selling_price.py
```

Each script will print sample predictions and evaluation metrics to the console, and display a plot comparing actual vs. predicted values.
